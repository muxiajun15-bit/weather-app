# Weather Guide

天候に合わせて背景が変わる日本語対応のPWA天気アプリです。

## 主な機能

- 現在地または都市名で現在の天気を表示
- 都市検索候補、検索履歴、お気に入り
- お気に入り都市の比較カード
- 12時間予報、5日予報、降水タイムライン
- 気温、降水確率、風、大気質から服装・持ち物を提案
- 天候連動の写真背景、ライト/ダーク切り替え、摂氏/華氏切り替え
- Service WorkerによるAPIキャッシュと前回データ復元

## 使い方

`weather.html` をブラウザで開くか、ローカルサーバーで配信してください。PWAとしてのインストールやService Workerの動作確認には `localhost` での表示が必要です。
